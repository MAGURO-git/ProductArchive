# 使用アセット

| アセット | 配布元 | 別途ダウンロード |
|---|---|---|
| VizVid | [JLChnToZ/VVMW](https://github.com/JLChnToZ/VVMW) | **必要**（同梱していません） |
| VRC_Starter Kit SDK3（UdonSharp版） | [BOOTH](https://booth.pm/ja/items/3435413) | 不要 |
| フリー効果音素材「第四隔壁開放」 | [DOVA-SYNDROME](https://dova-s.jp/se/play185.html) | 不要 |
| アルバム "都市記憶群" + 小物3DModels | [BOOTH](https://booth.pm/ja/items/1826356) | 不要 |
| HoloShield | [AdultLink/HoloShield](https://github.com/AdultLink/HoloShield) | 不要 |
| 【Unity】Parallax HUD Shader | [BOOTH](https://tsutsuji815.booth.pm/items/1547585) | 不要 |
| 【効果音】スポットライトが点灯する音 | [ポケットサウンド](https://pocket-se.info/archives/1319/) | 不要 |
