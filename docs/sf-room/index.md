# SF-ROOM for VRC

<span class="badge badge--vrc">VRChat World</span>

Sci-fi な部屋の VRChat 向けワールドです。アバターなどをディスプレイできる昇降機が付いています。

- 商品ページ: [BOOTH](https://maguro-vrc.booth.pm/items/2053652)
- サンプルワールド: [SF-ROOM for VRC](https://vrchat.com/home/world/wrld_abf5c3ac-6c13-4d67-8d68-d1b398e886b3)

## 必要環境

| 項目 | 内容 |
|---|---|
| Unity | 2022.3.6f1（他バージョンでの動作は保証していません） |
| ワールド容量 | 約65MB |
| 別途導入が必要なアセット | VizVid（[導入](install.md)を参照） |

ミラーとビデオプレイヤーは設定済みです。

!!! warning "テクスチャは別途ダウンロードが必要です"
    一部のテクスチャは外部クラウドストレージに置いています。同梱の `テクスチャのダウンロードリンク.txt` からアクセスしてください。

## SDK2 対応データについて

2020年5月から販売し、2024年3月に SDK3 へ対応しました。SDK2 対応データもダウンロードできます。**更新を行う場合、対象は SDK3 対応データのみ**です。

| 項目 | SDK2 データ | SDK3 データ |
|---|---|---|
| 適用される規約 | [UV ライセンス](https://uv-license.com/ja/license?utf8=%E2%9C%93&pcu=true&ccu=true&seu=true&veu=true&remarks=true) | [ショップ共通規約](../terms.md) |
| 2名までの共有（再配布の例外） | 可 | 不可 |
| パブリック化 | 可 | 可 |

SDK2 データは、**購入者本人を含む2名まで**であれば同じデータを共有して制作できます（追加の購入は不要）。SDK3 データにこの例外はありません。

!!! warning "共有できないデータがあります"
    2名までの共有をする場合でも、**BGM 音源は共有できません**。誤って渡さないようフォルダを分けてあります。Unity の Assets ＞ Export Package から書き出す際は、共有不可のフォルダにチェックを入れないでください。

    3名以上で共有する必要がある場合は、人数ぶんご購入ください。
