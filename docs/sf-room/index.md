## ご購入・導入前の確認事項

- **ギミックの動作保証・互換性について**:
  本商品は2024年3月時点の環境（Unity 2022.3.6f1 / 当時のSDK3）で制作・調整された製品です。制作当時の環境では動作確認を行っていますが、その後の最新 Worlds SDK 環境での網羅的なギミック動作確認は行っておらず、最新環境での動作は保証していません。また、特別な理由がない限り最新SDKへの継続的な追従アップデートは行っていません。
- **テクスチャのダウンロード**:
  高解像度テクスチャは外部ストレージに配置しています。同梱の「テクスチャのダウンロードリンク.txt」をご確認ください。
- **SDK3版のご利用を推奨**:
  過去バージョンの SDK2 対応データもダウンロード可能ですが、今後の更新やサポート対象は SDK3 対応データのみとなります。
- **展示モデルの高さ調整**:
  極端に背の高いモデルを置く場合、ハッチが開ききる前に頭頂部が床を貫通することがあります。必要に応じて配置位置やスケールを調整してください（詳細は[演出の調整](customize.md)）。
- **利用規約**:
  ワールドの利用条件は [利用規約](../terms.md) に準拠します。
