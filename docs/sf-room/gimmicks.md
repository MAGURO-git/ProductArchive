# ギミック一覧

## 昇降ギミック

操作パネルを使う（インタラクトする）と、床が下からせり上がります。格納するときは再度インタラクトします。

## 展示物を置く

展示したいオブジェクトを「`DisplayObjectHERE!!　昇降するオブジェクトを子に配置`」の配下に配置し、位置を調整します。

背の高いオブジェクトはハッチが開くタイミングとずれて貫通することがあります。その場合はアニメーションかスケールで調整してください。

## 展示物のライト

`RealtimeSpotLight` 以下で、展示物に当たるライトの色・強度・角度を調整できます。

## その他

ミラーとビデオプレイヤーが設定済みです。
