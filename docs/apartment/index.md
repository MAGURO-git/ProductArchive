# Apartment for VRC

<span class="badge badge--vrc">VRChat World</span>

高級アパートの内装の3Dモデルです。同梱の導入手順に沿ってセットアップすると、VRChat のワールドとして使えます。

- 商品ページ: [BOOTH](https://maguro-vrc.booth.pm/items/1509768)
- サンプルワールド: [Apartment for VRC](https://vrchat.com/home/world/wrld_fbc99e97-1a85-4f5d-b3e3-80d800823322)

## 必要環境

| 項目 | 内容 |
|---|---|
| VRChat SDK | SDK3（2022年9月に対応。SDK2 の配布は停止しました） |
| ワールド容量 | 約85MB |

## 導入

必要なアセットをインポート順に導入してからセットアップします。手順は [導入](install.md) を参照してください。

## 利用条件（簡易版）

| 項目 | 可否 |
|---|---|
| 営利目的での利用 | 可 |
| R-18 / R-18G を含むコンテンツでの利用 | 可（例外あり） |
| 改変 | 可（例外あり） |
| 再配布 | 不可（例外あり） |
| パブリック化 | 可 |

!!! info "再配布の例外"
    **購入者本人を含む2名まで**であれば、同じデータを共有して制作できます（追加の購入は不要）。それ以外の第三者へデータを渡すことはできません。

!!! info "R-18 / 改変の例外 — 同梱している再配布データ"
    本製品には、他の制作者による3Dモデル・効果音・BGM・テクスチャを再配布として含んでいます。これらには次の制限があります。

    - R-18 / R-18G を含むコンテンツでの**利用を認めていないものがあります**
    - 再配布しているテクスチャと音声素材は**改変できません**

    どのデータが該当するかは、利用規約の「再配布しているデータのライセンス一覧」で各ライセンスを確認してください。

同梱データのうち再配布物については、それぞれの規約に従ってください。詳細は[利用規約](https://docs.google.com/spreadsheets/d/1frp2qE5BP6009qW-P5lpX8KDs2rw0WihObpckiOGC3c/edit?usp=sharing)を確認してください。
