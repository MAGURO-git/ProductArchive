# Apartment for VRC

<span class="badge badge--vrc">VRChat ワールド</span>

高級アパートの内装の3Dモデルです。同梱の導入手順に沿ってセットアップすると、VRChat のワールドとして使えます。

- 商品ページ: [BOOTH](https://maguro-vrc.booth.pm/items/1509768)
- サンプルワールド: [Apartment for VRC](https://vrchat.com/home/world/wrld_fbc99e97-1a85-4f5d-b3e3-80d800823322)

## 必要環境

| 項目 | 内容 |
|---|---|
| VRChat SDK | SDK3（2022年9月に対応。SDK2 の配布は停止しました） |
| ワールド容量 | 約85MB |

## 導入

同梱の導入手順に沿ってセットアップしてください。

## 利用条件（簡易版）

| 項目 | 可否 |
|---|---|
| 営利目的での利用 | 可 |
| R-18 / R-18G を含むコンテンツでの利用 | 可（例外あり） |
| 改変 | 可 |
| 再配布 | 不可（例外あり） |
| シェア | 購入者を含む**最大2名**まで |
| パブリック化 | **不可** |

同梱データのうち再配布物については、それぞれの規約に従ってください。詳細は[利用規約](https://docs.google.com/spreadsheets/d/1frp2qE5BP6009qW-P5lpX8KDs2rw0WihObpckiOGC3c/edit?usp=sharing)を確認してください。
