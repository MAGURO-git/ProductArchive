# Apartment for VRC 利用規約

本製品には、ショップ共通の [利用規約](../terms.md) ではなく、この専用規約が適用されます。

## 営利目的での利用

**可能です。** ゲーム、映像、動画配信などにご利用いただけます。

本製品が直接ダウンロードできるような形式での販売・配布は禁止です。

VRChat 向けにセットアップしているため、VRChat 以外での動作は保証しません。VRChat や Unity のアップデートにより発生した不具合については可能な限り対応しますが、動作を保証するものではありません。

## R-18 / R-18G を含むコンテンツでの利用

**可能です（例外あり）。**

同梱している再配布データのなかには、利用を認めていないものがあります。[使用アセット](credits.md) で各データのライセンスを確認してください。

## 改変

**可能です（例外あり）。**

3Dモデルとテクスチャは改変できます。ただし、**再配布しているテクスチャと音声素材は改変できません**。

## 再配布

**禁止です（例外あり）。**

本製品に含まれるすべてのデータの再配布を禁止します。改変したものを配布・販売することも禁止です。

例外として、**購入者本人を含む最大2名**まで本製品を共有できます。共有を受けた方は、データを受け取った時点で本規約に同意したものとし、そのデータを第三者へ共有することはできません。

## パブリック化

**可能です。**

!!! note "2026-08-05 変更"
    従来はパブリック化を禁止していましたが、許可へ変更しました。モデルの一部を自作のワールドへ組み込んで公開することもできます。

## 同梱データについて

同梱している再配布データと、導入時にインポートする unitypackage については、それぞれの規約に従ってください。一覧は [使用アセット](credits.md) を参照してください。

## 免責

本製品のご利用により何らかの不都合や損害が発生したとしても、著作者は一切の責任を負いません。
