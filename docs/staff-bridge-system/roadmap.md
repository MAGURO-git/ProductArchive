# 開発状況

Staff Bridge System で、いま作っている機能と、今後対応する予定の機能、検討している機能を載せています。内容と時期は変わることがあります。

公開済みの変更は[更新履歴](changelog.md)を参照してください。

## 開発中 { #in-progress }

次の更新に向けて作業している機能です。

### 1.2.0

- プロップインベントリ：登録した小道具をメニューから出し入れ
    - ローカル：自分だけに見える
    - グローバル：全員に見える
- スイッチのカテゴリ分けとお気に入り
    - カテゴリのタブでスイッチを絞り込み
    - ★を付けたスイッチを「★」タブにまとめて表示
- 周りの声を下げる：インカムとメガホンの使用中に、周りの声を自分の側だけ小さくする
    - 下げる量は各自が設定
