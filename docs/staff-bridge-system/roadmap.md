# 開発状況

Staff Bridge System で、いま作っている機能と、今後対応する予定の機能、検討している機能を載せています。内容と時期は変わることがあります。

公開済みの変更は[更新履歴](changelog.md)を参照してください。

## 開発中 { #in-progress }

次の更新に向けて作業している機能です。

### 1.2.0

#### 新機能

- プロップインベントリ：登録したプロップをメニューから出し入れ
    - 同じプロップを複数個、同時に出せる
    - ローカル：自分だけに見える
    - グローバル：全員に見える

#### 機能改善

- スイッチ：カテゴリ分けとお気に入り
    - カテゴリでスイッチを絞り込み
    - よく使うスイッチをお気に入りに登録
- インカム・メガホン：使用中に周りの声を下げる
    - 話している間と、聞いている間の両方が対象
    - 下げる量は各自が設定

## 対応予定 { #planned }

対応することは決めていますが、まだ着手していない機能です。

- メッセージ：定型文の見た目を改善
    - 一覧を見やすく、選びやすくする

## 検討中 { #considering }

いただいた要望のうち、対応するかどうかや、どの形で提供するかを検討している機能です。

- 注文の取りまとめ：イベント中に受けた注文を、スタッフの間でまとめて扱えるようにする機能です。Staff Bridge System とは別のギミックとして開発することも含めて検討しています
