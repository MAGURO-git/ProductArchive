# スタッフの操作ガイド

SBSメニューの開き方と、ワールド内での操作を説明します。使うチャンネルや控室の場所は、主催の方に確認してください。

## スタッフになる { #staff-status }

| 種類 | なり方 | ほかの人の追加・削除 |
|---|---|---|
| 常設スタッフ | 主催の方が名簿に登録。既定では入室時に自動でスタッフになる | 現在スタッフONなら操作できる |
| 当日スタッフ | 切替スイッチを押すか、常設スタッフに追加してもらう | 操作できない |

それ以外のメニュー操作は共通です。切替スイッチは押した本人のスタッフON／OFFを切り替えます。設置場所は主催の方に確認してください。

常設スタッフの判定は**表示名の完全一致**です。名前を変えている場合は、主催の方へ連絡してください。

!!! note "当日スタッフの付与は再入場後も残ります"
    既定では、次のインスタンスでもスタッフに戻ります。付与を外したい場合は、入室中に常設スタッフへ依頼してください。

## メニューを開く { #open-menu }

| 環境 | 操作 |
|---|---|
| VR | 右スティックを下に倒して長押し |
| Desktop | Tabキーを長押し |

長押しは既定0.5秒です。キーや時間は主催の方が変更している場合があります。同じ操作でもう一度閉じられます。

メニューは開いた場所に固定され、そこから離れると自動で閉じます。左側のタブで画面を切り替えます。表示されるタブはイベントによって異なり、薄いタブは開けません。

![SBSメニュー](images/menu-teleport.png)

## テレポート { #teleport }

**行き先を選ぶ → 確定ボタンを押す**と移動します。選んだだけでは移動しません。

| 項目 | 操作・動作 |
|---|---|
| 登録地点 | 主催の方が用意した地点へ移動する |
| 在室スタッフ | 相手の背後へ移動し、同じ方向を向く |
| お気に入り | 行の★で一覧の上に固定する。スタッフは32人まで。退室するとリセットされる |
| 直前の地点へ戻る | 押すたびに現在地と直前の地点を入れ替える |

着地位置は人が重ならないよう少しばらつきます。「戻る」だけは元の位置へ正確に戻ります。

## インカム { #incom }

### チャンネルに参加する

チャンネルを選ぶと参加します。同じチャンネルの人には距離に関係なく声が届き、複数人が同時に話せます。**全体CHは、チャンネルに参加していない人も含めた全スタッフに届きます。**

![インカムタブ](images/menu-incom.png)

!!! warning "近くの人への聞こえ方を確認してください"
    既定では送信中の声はスタッフ以外に聞こえません。主催の方が「スタッフ限定モード」をOFFにしていると、近くの人には通常の声として聞こえます。

### 話す

| 方法 | 操作 |
|---|---|
| 発話ボタン | 押している間だけ送信。設定タブでトグルにも変更できる |
| Desktopキー | 割り当てたキーで送信。既定はT |
| VRジェスチャー | **右手**を耳に近づけてトリガーを保持。位置は主催の設定により肩・胸元の場合もある |

DesktopキーとVRジェスチャーは、メニューを閉じていても使えます。VRジェスチャーは押している間だけ送信します。

語尾が切れないよう、離してから停止まで既定0.3秒の待ち時間があります。連続送信は既定120秒で停止します。チャンネル変更・退出・スタッフOFFでも送信が止まります。

!!! warning "トグルはメニューを閉じても送信が続きます"
    視界のステータス表示で送信中か確認し、使い終わったらもう一度押して停止してください。

### 参加者を確認する

「メンバー」でチャンネルごとの参加者と、いま話している人を確認できます。自分の受信チャンネルで発話が始まったときと、全員が話し終えたときに小さな音が鳴ります。

![参加メンバー一覧](images/menu-incom-members.png)

## メガホン { #megaphone }

**スタッフ以外を含む、インスタンス内の全員へ声を届けます。** 開場・終了の案内などに使い、運営どうしの連絡には使わないでください。

| 方法 | 操作 |
|---|---|
| メニューのボタン | メガホンボタンを長押し |
| Desktopキー | 設定タブで割り当てたキーを使う。既定は割り当てなし |
| VRジェスチャー | **左手**を耳などの指定位置に近づけてトリガーを保持 |

ボタンとVRジェスチャーは既定0.5秒の保持で起動します。設定タブでボタンは長押し／トグル、「メガホンVR」は長押し／トグル／OFFを選べます。

- **長押し**：離すと停止します。
- **トグル**：離しても、メニューを閉じても続きます。もう一度押すとすぐに停止します。
- **メガホンVRをOFF**：VRジェスチャーを無効にします。ボタンとDesktopキーは使えます。方式を変更すると使用中のメガホンも止まります。

インカムとメガホンは同時に送信できません。受信は続きます。メガホンはスタッフOFF、または既定180秒の連続使用で停止します。使用中は視界のステータス表示で確認できます。

## 一斉メッセージ { #broadcast }

宛先と定型文を選び、スタッフへ送ります。宛先は全スタッフ・グループ・個人から選べます。グループと個人を重ねても、1人に届くのは1通だけです。人数が0のグループは選べません。

![メッセージタブ](images/menu-message.png)

### グループに入る

「所属グループを選択」を開き、班のボタンで入る／抜けるを切り替えます。複数に所属でき、選択は再入場後も残ります。「どのグループにも所属しない」を選ぶと、グループ宛の連絡を受け取らなくなります。

### 受信した内容を読む

受信すると通知ログに表示され、通知音が鳴ります。個人宛に指定されたメッセージには目印と枠が付き、長めに表示されます。送信した本人には送信確認音が鳴ります。

「ログを開く」で、受け取ったメッセージを新しい順に読み返せます。既定16件まで、受信時刻・送信者・本文が残ります。

!!! note "入室前のメッセージは読めません"
    過去のメッセージはあとから入室した人には表示されません。必要な連絡は再送を依頼してください。スタッフ以外には届きません。

## 通知ログ { #notice-log }

視界の隅に、メッセージ・タイマーの時間切れ・入退室・スタッフの増減・スイッチの操作が流れます。スタッフにだけ見え、メニューを閉じていても表示されます。

最大5件で、既定20秒後に消えます。個人宛のメッセージは40秒です。古い行ほど薄くなり、件数を超えると古い行から消えます。長い本文は折り返され、左の色帯で種別を区別できます。

設定タブで**左下／左上／表示しない**を選べます。過ぎた連絡はメッセージの受信ログ、入退室はタイマー・ログタブで読み返してください。

## タイマー・ログ { #timer }

![タイマー・ログタブ](images/menu-timer.png)

タイマーは **＋30秒／＋1分／＋5分** で時間を足してから開始します。

| 種類 | 動作 |
|---|---|
| 共有タイマー | スタッフ全員に同じ残り時間が見える。**開始と取消は2回押し**。1回目で文言が変わり、既定5秒以内にもう一度押すと確定する |
| ローカルタイマー | 自分だけのタイマー。確認の2回押しは不要 |
| ストップウォッチ | 自分だけの経過時間を計る |

タイマーが0になると、通知ログと短い音で知らせます。音量は設定タブの「通知音」で調整できます。通知ログを非表示にしても音は鳴り、通知音を0にすると無音になります。

下側の入退室ログは最新6行です。入室は緑、退室は赤で表示され、「ログを開く」で全画面になります。**自分が入室する前の出入りは含まれません。**

## ノート { #note }

![ノートタブ](images/menu-note.png)

| 欄 | 使い方 |
|---|---|
| 左の共有メモ | 主催の方が用意した内容を読む。上のボタンでページを切り替える |
| 右の自分用メモ | 自分だけのメモを書く。再入場後も残る。12行を超える入力・貼り付けは取り消され、操作音が鳴る |

「共有メモを表示」「自分用メモを表示」で、視界の隅に出したままにできます。両方同時に表示でき、メニューを閉じても読めます。

隣の−／＋で表示行数を調整します。共有は1〜15行、自分用は1〜12行です。2枚を置ける縦幅には上限があり、収まらない＋は薄くなります。その場合はもう片方の行数を減らしてください。下のバーは共有・自分用・残りの割合を示し、自分用メモは書いた行数まで場所を使います。

文字の大きさは設定タブで小／中／大から選べます。表示の選択・行数・文字の大きさは再入場後も残ります。

## スイッチ { #switch }

手元からワールドのギミックを動かします。何が並んでいるかはイベントによって異なるため、主催の方に確認してください。

![スイッチタブ](images/menu-switch.png)

**行を選ぶ → 確定ボタンを押す**と実行します。11件目からは右端の▲▼でページを送ります。

最後に実行した内容はパネルに残り、「実行履歴」で誰がいつ押したかを直近64件まで確認できます。履歴はスタッフ共通で、自分の入室前の分も見えます。

操作結果がグローバルかローカルかは、主催の方が設定した送り先のギミックによって異なります。

## 設定 { #settings }

設定は自分にだけ適用され、同じワールドへの再入場後も残ります。

![設定タブ](images/menu-settings.png)

| 項目 | 内容 |
|---|---|
| 操作音 | UI操作音・インカムの送信音・メッセージ送信音の音量 |
| 通知音 | インカムの受信音・メッセージ通知音・タイマー到達音の音量 |
| UI サイズ／UI 距離 | メニューの大きさと距離。各50〜150%／70〜160%。開いたまま調整できる |
| ボタン | 発話を長押し／トグルから選ぶ。インカムとメガホンで別々に設定できる |
| Desktopキー | 発話に使うキー。インカムとメガホンで別々に設定できる。VRでは無効 |
| メガホンVR | 左手の操作を長押し／トグル／OFFから選ぶ |
| 通知ログ | 左下／左上／表示しないから選ぶ |
| 表示位置を調整 | 通知ログと視界ノートを別々に横・縦へ移動する。各±20 cm |
| 視界ノートの文字 | 小／中／大から選ぶ |

同じDesktopキーをインカムとメガホンの両方には割り当てられません。あとから選んだ側が優先され、もう片方はOFFになります。

表示位置は0 cmが標準で、プラスにすると右／上へ動きます。共有メモと自分用メモは一緒に動きます。各「位置を初期化」は位置だけを0 cmに戻し、通知ログの左下／左上／表示しないは変えません。

「設定を初期化」で設定全体を既定値に戻せます。

!!! warning "トグルは閉じても停止しません"
    インカム・メガホンとも、使い終わったらもう一度押して止めてください。インカムのVRジェスチャーは押している間だけ、メガホンは「メガホンVR」で選んだ方式に従います。

## スタッフ管理 { #staff-manage }

**常設スタッフで、現在スタッフONの人だけ**が開けます。

![スタッフ管理タブ](images/menu-grant.png)

| 一覧 | 操作 |
|---|---|
| 左の在室者 | 行を選んで確定すると、当日スタッフにする |
| 右の当日スタッフ | 行を選んで確定すると、当日スタッフから外す |

常設スタッフは外せないため一覧に出ません。入退室で一覧が更新されると選択が解除されます。各一覧は既定32人までで、収まらない分は「他 N 人」と表示されます。

## スタッフ限定の場所・設備 { #staff-only }

スタッフになると、主催の設定に応じて見た目や利用できる設備が切り替わります。

- スタッフだけが通れる壁・押せるスイッチ
- スタッフだけに見えるオブジェクト、またはスタッフには隠れるオブジェクト
- 在室スタッフの一覧ボード・頭上の目印

## 困ったとき { #help }

| 症状 | 確認すること |
|---|---|
| スタッフにならない | 表示名が登録時と同じか。違う場合は主催の方へ連絡する |
| メニューが出ない | スタッフになっているか、長押しが足りているか |
| インカムが聞こえない | チャンネルに参加しているか。一度チャンネルを抜けて入り直す |
| 声が届かない | 送信中か。長時間の送信で自動停止していないか |

解決しない場合はワールドに入り直し、それでも直らなければ主催の方へ連絡してください。メニュー右上のバージョンも伝えると確認に役立ちます。
