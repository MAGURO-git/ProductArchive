# 更新履歴

バージョン表記はセマンティックバージョニング（MAJOR.MINOR.PATCH）に従います。

お手元のバージョンは、ワールド内でメニューを開いたときのヘッダー右上で確認できます。

---

## 1.0.0（未リリース）

初回リリース。

**スタッフメニュー**

- 手元パネルにテレポート／一斉メッセージ／インカム操作を統合
- メンバー一覧・メッセージログの各ページ
- タブの並べ替えと ON / OFF（設定を引き継いだままメニューを作り直せる）
- 件数の多いリストは右端の ▲▼ ボタンで送る（Desktop でも行ボタンを確実に押せるようにするため、ドラッグでのスクロールは使わない）
- 配色テーマ11種＋カスタム（役割色12色を個別編集）、フォント差し替え
- 生成済みメニューへの再着色（行き先・参照は保持）

**タイマー・ログ／ノート／スイッチ**

- 共有タイマー（全員に同じ残り時間。開始と取消は2回押し）、ローカルタイマー、ストップウォッチ
- 入退室ログ（入室＝緑・退室＝赤。全画面の一覧ページつき）
- ノート（進行台本のページ表示と、自分だけの走り書きメモ）
- スイッチ（手元からワールド内のギミックへイベントを送る。最後の発火内容は同期表示）

**通知ログ**

- メッセージ受信・タイマー到達・入退室・スタッフ権限の変化・スイッチ発火を、視界の隅の1本のログに集約
- 種別ごとの色帯・時刻つき、本文は省略せず折り返し。最大5件・1件20秒（自分宛は枠つきで40秒）
- 出す位置は各自が左下／右下／表示しないから選べる（再入場後も保持）

**インカム（無線）**

- チャンネル参加・発話ボタン（押している間だけ送信）／VR 耳元ジェスチャー発話・発話者表示
- スタッフ限定モード（同チャンネルのみに聞こえる密話）
- チャンネル参加・名簿の自動再送による取りこぼし回復
- 受信ビープ

**メガホン**

- メガホン（長押し中だけ来場者を含む全員へ拡声。無線の送信とは相互排他）

**スタッフ管理・個人設定**

- スタッフ管理タブ（在室者を当日スタッフにする／当日スタッフを外す。常設スタッフのみ操作可）
- 設定タブ（操作音／通知音の音量、UI サイズ・距離、発話方式の長押し／トグル、DT キー発話、通知ログの位置）。PlayerData に保存し再入場で復元
- 送信中・メガホン使用中を表示する視界ステータス

**一斉メッセージ**

- プリセット編集（カテゴリ分け対応）、全スタッフ宛／個別スタッフ宛
- 受信ログ・受信通知音・送信確認音・自分宛の強調表示

**テレポート**

- 登録地点および在室スタッフへの移動
- お気に入り（★）、選択中ハイライト
- 在室スタッフへは背後に着地し、着地後は相手と同じ向きを向く
- 着地位置のばらつき、直前地点へ戻る

**スタッフ限定オブジェクト**

- スタッフゲート（非スタッフを通さない壁）、スタッフだけ見える／一般だけ見える表示切替
- スタッフ専用ボタン（コライダー制御・発火先呼び出しの2方式）
- 在室スタッフ一覧ボード、頭上マーカー

**エディタ支援**

- セットアップ窓（左サイドバーのページ式。導入／カスタマイズ／こまったら）
- カスタマイズの各ページによく使う設定を集約（メニュー構成・チャンネル名・メガホンや無線の既定値・DTキー候補・名簿）
- インカムの一時停止（他の音声ギミックと同居させる回の切り替え）
- セットアップ診断・自動修復、配置後の再リンク
- アップロード前チェック（ログ出力の消し忘れ防止）
- テレポート先の後編集、定型メッセージ編集
- 名簿プリセットの書き出し／読み込み
- インカム聴こえ方マトリクス検査
- 問い合わせ用の状態レポート生成（表示名・パス・ワールドIDは含めない）
- スタッフ UI のカメラ非表示化

**その他**

- UI 操作音（サウンド文法に基づく操作音10種）
- 開閉・お気に入り・確定ボタンのマイクロアニメーション
- チュートリアル形式のサンプルシーン
