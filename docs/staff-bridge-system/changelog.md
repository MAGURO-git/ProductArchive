# Staff Bridge System 更新履歴

## 1.2.0（公開日未定）

- **周りの声を下げる**：インカム・メガホンの使用中、周りの声を自分の側だけ小さくする機能を追加。減衰量は設定の「基本」タブでスタッフ各自が指定可能（初期値は「下げない」）
- **スイッチのカテゴリとお気に入り**：スイッチをカテゴリ（最大9個）に分類してタブで絞り込む機能、および★マークによるお気に入りタブへの登録機能を追加（セットアップウィンドウでドラッグして分類）
- **プロップインベントリ**：登録した小道具（プロップ）を、SBSメニューから手元（ローカル）や全員の前（グローバル）に出し入れする機能を追加（初期状態はオフ。セットアップウィンドウの「プロップを使う」で有効化）
- **診断・修復の拡張**：既存ワールド向けに、周りの声を下げる機能の追加、プロップタブの追加、および Prefab の再リンク処理に対応
- **メニューを作り直すときの引き継ぎ強化**：メニューを作り直すときに、スイッチのカテゴリ設定およびプロップの登録設定を維持して引き継ぐよう改善
- **診断・修復の項目名の変更**：画面の表示を整理しました。旧「メニューを手前に描く」は「前面表示に設定」、旧「インカムの音声制御役」は「インカムの音声制御（PA Supervisor）」です。機能は変わりません。

※既存ワールドからの更新手順は [既存のワールドを更新する](install.md#update) を参照してください。

## 1.1.0（2026-10-30）

- **インカム・メガホンの声の大きさ調整**：ワールド全体の既定値（セットアップウィンドウ）およびスタッフ各自の調整スライダー（設定タブ）を追加
- **メニュー・視界表示の前面描画**：開いたSBSメニューや視界表示（状態の帯・ノート・通知ログ）がワールドのオブジェクトに隠れないよう改善
- **診断・修復の拡張**：既存シーン向けに声の大きさ調整や前面描画を追加する項目に対応

※既存ワールドからの更新手順は [既存のワールドを更新する](install.md#update) を参照してください。
