# 更新履歴

## 1.2.0（2026-11-15）

- **周りの声を下げる**：インカム・メガホンの使用中、周りの声を自分の側だけ小さくする機能を追加。減衰量は設定の「インカム」タブの「使用中の周りの声」でスタッフ各自が指定可能（初期値は「下げない」）
- **スイッチのカテゴリとお気に入り**：スイッチをカテゴリ（最大9個）に分類してタブで絞り込む機能、および★マークによるお気に入りタブへの登録機能を追加（セットアップウィンドウでドラッグして分類）
- **スイッチタブの表示件数の変更**：1ページあたりの表示件数を20件から14件に変更（15件以上はページ送り）
- **プロップインベントリ**：登録した小道具（プロップ）を、SBSメニューから手元（ローカル）や全員の前（グローバル）に出し入れする機能を追加。初期状態はオフ。セットアップウィンドウの「プロップを使う」で有効化
- **メニュー構成ページの改善**：メニュー構成の一覧から「設定」の行を除外（メニューには常に表示）。「並び順を初期に戻す」ボタンの追加。プロップタブの並べ替えに対応。プロップをオフにして作り直した際に登録も削除されるよう改善
- **メニューを作り直すときの引き継ぎ強化**：次の設定を引き継ぐよう改善
    - スイッチのカテゴリ
    - プロップの登録
    - インカム・メガホンの声の大きさ（既定値と調整幅）
    - 周りの声を下げる設定
    - 操作音
- **セットアップウィンドウのリンク追加**：ウィンドウ右上に「更新履歴」「開発状況」のリンクボタンを追加
- **診断・修復の拡張**：既存ワールド向けに、周りの声を下げる機能の追加、プロップタブの追加、およびPrefabの再リンク処理に対応
- **診断・修復の案内追加**：アンパック等のメニュー向けに「スイッチのカテゴリ分けとお気に入り（未配置）」のお知らせを追加。ボタンはなく、メニューを作り直すと使えるようになる旨を案内
- **設定の項目名の変更**：「インカム」タブの「声の大きさ」を「スピーカー音量」に、「基本」タブの「設定を初期化」を「全設定を初期化」に変更。スピーカー音量の数値表示は廃止
- **診断・修復の項目名の変更**
    - 旧「メニューを手前に描く」→「前面表示に設定」
    - 旧「インカムの音声制御役」→「インカムの音声制御（PA Supervisor）」

※既存ワールドからの更新手順は [既存のワールドを更新する](install.md#update) を参照してください。

## 1.1.0（2026-10-30）

- **インカム・メガホンの声の大きさ調整**：ワールド全体の既定値（セットアップウィンドウ）およびスタッフ各自の調整スライダー（設定タブ）を追加
- **メニュー・視界表示の前面描画**：開いたSBSメニューや視界表示（状態の帯・ノート・通知ログ）がワールドのオブジェクトに隠れないよう改善
- **診断・修復の拡張**：既存シーン向けに声の大きさ調整や前面描画を追加する項目に対応

※既存ワールドからの更新手順は [既存のワールドを更新する](install.md#update) を参照してください。
