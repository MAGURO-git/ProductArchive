# よくある質問

## 導入について

既存のワールドに後付けできますか？
:   できます。手順は新規のワールドと同じです。

インカムを使わない予定でも FukuroUdon は必要ですか？
:   必要です。同梱の Prefab が参照しています。

Quest（Android）に対応していますか？
:   PC 専用です。Quest 実機での動作確認は行っていません。

何人規模のインスタンスまで動作しますか？
:   本製品のもとになったプロトタイプを30人規模のイベントで運用し、安定して動作しました。それを超える規模での動作は確認していません。ワールドの構成や同時に動く他のギミックによっても変わります。本番前に、実際のワールドでセットアップと各機能の動作を必ずご確認ください。

UI の言語は？
:   日本語です。

アバター用のギミックとして使えますか？
:   いいえ。VRChat のワールド専用です。

## 機能について

来場者にメッセージを表示できますか？
:   できません。一斉メッセージの送信先はスタッフのみです。

テレポート先はいくつまで登録できますか？
:   16件までです。

メニューの開き方を変えられますか？
:   Desktop のキーは Tab / F1〜F4 / B / G / N から選べます。長押し時間としきい値も調整できます。

スタッフ以外にもメニューを見せられますか？
:   いいえ。メニューはスタッフ状態のプレイヤーだけが開けます。

お気に入りのテレポート先は保存されますか？
:   インスタンス内でのみ有効です。退室するとリセットされます。

## ライセンス・購入について

ここは要約です。正式な利用条件は [Staff Bridge System 利用規約（PDF）](https://drive.google.com/file/d/1XA7iCCnva2MOD1Dk9hp_Xe6_dKWmGWnn/view?usp=drive_link) を参照してください。

複数のワールドで使えますか？
:   購入者本人のワールドであれば使えます。追加購入は不要です。

個人ライセンスとチームライセンスはどう使い分けますか？
:   基準は「何人が編集したか」ではなく、**ファイルに何人がアクセスできる状態か**です（git やクラウドでの共有を含みます）。アクセスできる人は全員ライセンスが必要です。2人までは個人ライセンスを人数分購入するほうが安く、3人以上はチームライセンスのほうが安くなります。ワールドに組み込んだ後、スタッフや来場者として使うだけの人はカウント対象外です（人数無制限・購入不要）。

チームライセンスは、イベントごとに必要ですか？
:   いいえ。単位は**イベントではなく運営団体**です。同じ運営団体が名称の異なるイベントを複数開催する場合、そのいずれにも追加購入なく使えます。

運営が違うイベントに、同じ制作者として参加する場合はどうなりますか？
:   運営団体ごとにライセンスが必要です。同一かどうかはイベント名ではなく**運営の主体**で判断します。たとえば、別々の運営チームから2つのイベントのワールド制作を依頼された場合、制作者が同じでも2つ分のライセンスが必要になります。

個人ライセンスとチームライセンスで内容物は違いますか？
:   同一です。違いはライセンス条件のみです。

依頼を受けて作るワールドに組み込めますか？
:   組み込めます。ただし納品できるのは、組み込みが済んだワールドまでです。ギミックのファイル（unitypackage やアセット）を依頼主へ渡すことはできません。依頼主自身がギミックを編集する場合は、依頼主による購入が必要です。

購入後の返金はできますか？
:   対応していません。体験ワールドで動作を確認のうえご購入ください。

アップデートはどう受け取りますか？
:   BOOTH の購入履歴（ライブラリ）から再ダウンロードできます。
