## ライセンス・購入について

ここは要約です。正式な利用条件は [Staff Bridge System 利用規約（PDF）](https://drive.google.com/file/d/1Y1xBQFlrfcBY5iI4gYFHOwRgYQo4pm7a/view?usp=sharing) を参照してください。

複数のワールドで使えますか？
:   購入者本人のワールドであれば使えます。追加購入は不要です。

個人ライセンスとチームライセンスはどう使い分けますか？
:   基準は「何人が編集したか」ではなく、**ファイルに何人がアクセスできる状態か**です（git やクラウドでの共有を含みます）。アクセスできる人は全員ライセンスが必要です。2人までは個人ライセンスを人数分購入するほうが安く、3人以上はチームライセンスのほうが安くなります。ワールドに組み込んだ後、スタッフやスタッフ以外として使うだけの人はカウント対象外です（人数無制限・購入不要）。

チームライセンスは、イベントごとに必要ですか？
:   いいえ。単位は**イベントではなく運営団体**です。たとえば運営団体Aが毎月の定例イベントと年1回の周年イベントを開くとします。どちらも主催は運営団体Aなので、1つで両方に使えます。

自分が複数の運営団体に関わっている場合はどうなりますか？
:   運営団体ごとにライセンスが必要です。あなたが運営団体Aのスタッフだとします。別の運営団体Bのイベントにも手伝いで参加する場合、運営団体Aのライセンスは運営団体Bでは使えません。運営団体Bの側で用意してもらってください。同一かどうかは**運営の主体**で判断します。別々の運営団体から2つのイベントのワールド制作を依頼された場合、制作者が同じでも2つ分必要です。

クレジット表記は必要ですか？
:   必須ではありません。記載していただける場合は `© M.G.R` でお願いします。

個人ライセンスとチームライセンスで内容物は違いますか？
:   同一です。違いはライセンス条件のみです。

依頼を受けて作るワールドに組み込めますか？
:   組み込めます。ただし納品できるのは、組み込みが済んだワールドまでです。ギミックのファイル（unitypackage やアセット）は依頼主へ渡せません。依頼主自身がギミックを編集する場合は、依頼主による購入が必要です。

購入後の返金はできますか？
:   対応していません。[サンプルワールド](https://vrchat.com/home/world/wrld_01cbbb48-44ce-4761-9baa-6f4ef87fbbfd/info)で動作を確認のうえご購入ください。

アップデートはどう受け取りますか？
:   BOOTH の購入履歴（ライブラリ）から再ダウンロードできます。
