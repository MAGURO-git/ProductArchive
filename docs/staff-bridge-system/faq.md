# よくある質問

## 導入について

既存のワールドに後付けできますか？
:   できます。手順は新規のワールドと同じです。

インカムを使わない予定でも FukuroUdon は必要ですか？
:   必要です。同梱の Prefab が参照しています。

Quest（Android）に対応していますか？
:   PC 専用です。Quest 実機での動作確認は行っていません。

何人規模のインスタンスまで動作しますか？
:   本製品のもとになったプロトタイプを40人規模のイベントで運用しました。それを超える規模での動作は確認していません。ワールドの構成や同時に動く他のギミックによっても変わります。本番前に、実際のワールドでセットアップと各機能の動作を必ずご確認ください。

UI の言語は？
:   日本語です。

アバター用のギミックとして使えますか？
:   いいえ。VRChat のワールド専用です。

## 機能について

来場者にメッセージを表示できますか？
:   できません。一斉メッセージの送信先はスタッフのみです。

テレポート先はいくつまで登録できますか？
:   16件までです。

メニューの開き方を変えられますか？
:   Desktop のキーは Tab / F1〜F4 / B / G / N から選べます。長押し時間としきい値も調整できます。

当日その場でスタッフを増やせますか？
:   増やせます。常設スタッフが[スタッフ管理タブ](usage.md#staff-manage)から在室者を当日スタッフにできます。外すのも同じ場所です。スタッフ切替スイッチを設置する方法もあります。

音量やメニューの大きさは変えられますか？
:   [設定タブ](usage.md#settings)から各自で変更できます。操作音と通知音は別々に調整でき、設定は再入場しても残ります。ワールド制作者は、その初期値を決められます。

スタッフ以外にもメニューを見せられますか？
:   いいえ。メニューはスタッフ状態のプレイヤーだけが開けます。

声を操作する他のギミックと併用できますか？
:   干渉する可能性があります。個室・ボイスゾーン・拡声など、プレイヤーの声を操作するギミックはインカムと同じ仕組みを使うため、どちらかが意図どおりに動かなくなります。拡声だけなら本製品の[メガホン](usage.md#megaphone)でまかなえます。他のギミックを使う回は、セットアップ窓の**インカム**ページにある**インカムの一時停止**で本製品側を止められます（[運用ガイド](operation.md#incom-power)）。

メニューのフォントは変えられますか？
:   変えられます。未指定のままなら前提パッケージの日本語フォント（VRChat のフォールバックと同じ NotoSansJP）が使われ、そのままで日本語が表示されます。任意の TMP フォントアセットを指定すると、生成されるテキストがそのフォントになります（[見た目のカスタマイズ](customize.md#font)）。

お気に入りのテレポート先は保存されますか？
:   インスタンス内でのみ有効です。退室するとリセットされます。

使わないタブを消せますか？
:   消せます。セットアップ窓の「メニュー構成」ページで、タブの ON / OFF と並び順を決めて作り直します（「設定」タブは常に ON）。テレポート先・CH名・定型文・ノートの内容などは引き継がれます。

視界に出る通知が邪魔なときは？
:   各自が[設定タブ](usage.md#settings)で、左下・右下・表示しないから選べます。設定は再入場しても残ります。

進行台本（ノート）は誰が編集しますか？
:   ワールド制作者です。セットアップ窓の「メニュー構成」ページから「ノート編集」を開いて書き換えます。ワールド内の入力欄は各自の走り書き用で、他の人には見えず、退室すると消えます。

スイッチから、どんなギミックでも動かせますか？
:   Udon のイベントを受け取れるギミックなら、UdonSharp 製・Udon Graph 製のどちらでも指定できます。ただし保証しているのは「イベントを1回送る」ところまでです。全員の画面で同じ状態になるかどうかは、送り先のギミックの作りによります。

オブジェクトを出し入れするだけなら、受け側も作る必要がありますか？
:   いりません。同梱の `StaffObjectToggle` を使ってください。**対象**に GameObject を並べ、スイッチページのイベント名を `Toggle`（`TurnOn` / `TurnOff` も可）にすれば、鏡・照明・ゲートなどをまとめて切り替えられます。**同期する**を ON にすると、実行した1人が Owner を取って状態を書き、全員へ配ります。レイトジョイナーにも反映されます。OFF なら押した本人の画面だけが変わります。サンプルシーンの STEP 8 に両方を置いてあります。

## ライセンス・購入について

ここは要約です。正式な利用条件は [Staff Bridge System 利用規約（PDF）](https://drive.google.com/file/d/1Y1xBQFlrfcBY5iI4gYFHOwRgYQo4pm7a/view?usp=sharing) を参照してください。

複数のワールドで使えますか？
:   購入者本人のワールドであれば使えます。追加購入は不要です。

個人ライセンスとチームライセンスはどう使い分けますか？
:   基準は「何人が編集したか」ではなく、**ファイルに何人がアクセスできる状態か**です（git やクラウドでの共有を含みます）。アクセスできる人は全員ライセンスが必要です。2人までは個人ライセンスを人数分購入するほうが安く、3人以上はチームライセンスのほうが安くなります。ワールドに組み込んだ後、スタッフや来場者として使うだけの人はカウント対象外です（人数無制限・購入不要）。

チームライセンスは、イベントごとに必要ですか？
:   いいえ。単位は**イベントではなく運営団体**です。同じ運営団体が名称の異なるイベントを複数開催する場合、そのいずれにも追加購入なく使えます。

運営が違うイベントに、同じ制作者として参加する場合はどうなりますか？
:   運営団体ごとにライセンスが必要です。同一かどうかはイベント名ではなく**運営の主体**で判断します。たとえば、別々の運営チームから2つのイベントのワールド制作を依頼された場合、制作者が同じでも2つ分のライセンスが必要になります。

クレジット表記は必要ですか？
:   必須ではありません。記載していただける場合は `© M.G.R` でお願いします。

個人ライセンスとチームライセンスで内容物は違いますか？
:   同一です。違いはライセンス条件のみです。

依頼を受けて作るワールドに組み込めますか？
:   組み込めます。ただし納品できるのは、組み込みが済んだワールドまでです。ギミックのファイル（unitypackage やアセット）を依頼主へ渡すことはできません。依頼主自身がギミックを編集する場合は、依頼主による購入が必要です。

購入後の返金はできますか？
:   対応していません。サンプルワールドで動作を確認のうえご購入ください。

アップデートはどう受け取りますか？
:   BOOTH の購入履歴（ライブラリ）から再ダウンロードできます。
