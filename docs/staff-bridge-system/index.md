## できること

スタッフになったプレイヤーの手元に専用メニューが表示されます。

- 移動と連絡 — テレポート（登録地点・在室スタッフ）／インカム／メガホン／一斉メッセージ
- 進行 — 共有タイマーと自分用タイマー／ノート（共有メモと自分用メモ）／通知ログ／入退室ログ
- 運営 — 当日スタッフの追加と削除／手元からワールド内のギミックへイベントを送るスイッチ
- 各自の調整 — 音量・UI サイズ・発話方式・通知ログの位置（再入場後も保持）    

タブは並べ替えられ、使わないものは非表示にできます。

シーン側には、スタッフ限定オブジェクト（スタッフだけが見える／通れる／押せる）、在室スタッフ一覧ボード、頭上マーカーを設置できます。

イベントごとのカスタマイズは Unity 上の専用ウィンドウから行います。メニュー構成、テレポート先、定型文、配色テーマ、スタッフ名簿などの設定を、Inspectorを直接操作することなく編集可能です。また、設定の不備は診断・修復機能により一括で修正できます。

各機能の詳細、設定ページへの案内、非対応事項については [機能一覧](features.md) にまとめてあります。

## ご購入前に必ずご確認ください { #before-you-buy }

イベント当日に円滑に運用できるよう、仕様上の制約や動作範囲などをまとめました。ご購入前に必ずご一読ください。

**動作を確認した規模は40人です。** もとになったプロトタイプを40人規模のイベントで運用しました。それを超える規模では確認していません。

**プレイヤーの音声を動的に制御する他のギミックとは同時にご使用いただけません。** 防音室、個室、ボイスゾーン、全体音量調整、拡声など、声の届く距離やゲインを動的に書き換えるギミックは、インカムと同じ VRChat の音声設定（SetVoiceDistanceFar 等）を操作するため、競合して意図通りに動作しなくなります。そのため、ワールドごとに防音室ギミックか本システムのインカム機能のいずれか一方を選択して導入いただく必要があります。なお、音声機能の切り替えは[インカムの一時停止](operation.md#incom-power)から行えます。        

**スタッフ判定を使用するオブジェクト（ギミック）は1ワールドにつき最大128個までです。** 上限を超えたオブジェクトについては、スタッフ判定の動的更新が行われません。

**PC 専用です。** Quest 実機での動作確認は行っていません。

**前提パッケージが必須となります。** 本製品は FukuroUdon（MimyLab製）を利用しています。本製品パッケージには同梱されておりませんので、事前にVCCまたはALCOMから導入してください。

**スイッチ機能が保証するのは「ギミックへイベントを1回送信する」ところまでです。** イベント受信側のギミックが、参加プレイヤー全員の画面で完全に同期・再現されるかどうかは、受信側ギミック自体の同期設計に依存します。単純なGameObjectの表示・非表示の切り替えだけであれば、同梱の `StaffObjectToggle` で対応可能です。

!!! warning "本番前に実機で確認してください"
    ワールドの構成や同時に動く他のギミックによって、想定どおりに動作しないことがあります。本番と同じワールドで一通りの機能を動かして確認してください（[本番前の確認](operation.md#pre-event-check)）。

    イベント当日に不具合が生じた場合や、それによって進行に生じた損害について、当方では責任を負いかねますのであらかじめご了承ください。

## スタッフの付与について

スタッフの付与方法は「表示名ホワイトリスト」「スタッフ切替スイッチ」「メニューのスタッフ管理タブ」の3通りです。スイッチは触れた本人がスタッフ ON / OFF できるため、設置場所にはご注意ください。詳しくは [運用ガイド](operation.md#staff-detection) を参照してください。
