# 機能一覧

本製品に入っている機能の一覧です。各行の「詳しくは」から使い方・設定項目へ移動できます。

## 手元メニュー

スタッフになったプレイヤーだけが開けるメニューです。タブは並べ替えでき、使わないものは非表示にできます。

| 機能 | できること | 詳しくは |
|---|---|---|
| テレポート | 登録した地点と、在室スタッフのところへ移動する。相手の背後に着地する。★でお気に入りに入れると一覧の上に並ぶ | [使い方](usage.md#teleport) / [設定](reference.md#teleport) |
| インカム（無線） | 同じチャンネルに参加している人だけに聞こえる通話。参加中のメンバーと、いま話している人が一覧に出る | [使い方](usage.md#incom) / [設定](reference.md#incom) |
| メガホン | スタッフ以外を含む全員に距離を無視して声を届ける。ボタン長押し／Desktopキー／VRジェスチャー（左手）の3通りで始められる | [使い方](usage.md#megaphone) / [設定](reference.md#megaphone) |
| 一斉メッセージ | 全スタッフ、宛先グループ、選んだスタッフへ定型文を送る。グループと個人はまとめて選べ、複数に当てはまる人にも1通だけ届く | [使い方](usage.md#broadcast) / [設定](reference.md#broadcast) |
| タイマー | 全員に見える共有タイマーと、自分だけのタイマー・ストップウォッチ | [使い方](usage.md#timer) / [設定](reference.md#timer) |
| 入退室ログ | 誰がいつ入って出たかの記録 | [使い方](usage.md#timer) / [設定](reference.md#join-log) |
| ノート | 進行台本の閲覧と、自分だけの走り書きメモ | [使い方](usage.md#note) / [設定](reference.md#cue) |
| スイッチ | 手元からワールド内のギミックへイベントを送る | [使い方](usage.md#switch) / [設定](reference.md#trigger) |
| 通知ログ | 受信・タイマーの時間切れ・人の出入りを、視界の隅の1本のログにまとめて流す | [使い方](usage.md#notice-log) / [設定](reference.md#notice-log) |
| スタッフ管理 | 在室者を当日スタッフにする／当日スタッフを外す。常設スタッフだけに出るタブ | [使い方](usage.md#staff-manage) / [設定](reference.md#grant-panel) |
| 設定 | 音量・UI サイズ・発話方式・通知ログの位置を各自で調整する。再入場しても残る | [使い方](usage.md#settings) / [既定値](reference.md#settings-defaults) |

## シーンに置くもの

| 部品 | できること | 詳しくは |
|---|---|---|
| スタッフ切替スイッチ | 触れた本人がスタッフ ON / OFF になる | [運用](operation.md#staff-detection) |
| スタッフ一括解除スイッチ | 当日スタッフを全員まとめて外す（2回押しで確定・常設スタッフのみ操作可） | [運用](operation.md#staff-detection) |
| スタッフ専用スイッチ | スタッフだけが操作できるスイッチ。非スタッフが押すと拒否メッセージが出る | [導入](install.md#single-prefab) |
| スタッフゲート | スタッフだけが通れる壁 | [導入](install.md#single-prefab) |
| スタッフ限定オブジェクト | スタッフだけに見せる／スタッフには隠す／スタッフだけ押せるようにする | [使い方](usage.md#staff-only) / [設定](reference.md#staff-only-objects) |
| 在室スタッフ一覧ボード | いま入室しているスタッフ名を掲示する | [導入](install.md#single-prefab) |
| 頭上マーカー | スタッフの頭上に目印を出す | [導入](install.md#single-prefab) |

既存のオブジェクトは、置き直さずに右クリックからスタッフ限定へ変えられます（[導入](install.md#staff-only-existing)）。

## Unity 側の編集ツール

Inspector を直接触らずに済むよう、専用ウィンドウ（**Tools ＞ MGR ＞ Staff Bridge System ＞ セットアップ**）から編集します。

| ページ | できること | 詳しくは |
|---|---|---|
| セットアップ | 一式をボタン1つで配置し、相互の接続まで済ませる | [導入](install.md) |
| Prefab を個別に置く | 部品を1つずつ足す。置くと同時に名簿へ接続される | [導入](install.md#single-prefab) |
| メニュー構成 | タブの並べ替えと ON / OFF。テレポート先・定型メッセージ・ノートの編集。設定を引き継いだまま作り直せる | [やりたいことから探す](howto.md) |
| メニューの出かた | 開く操作、出る位置と大きさ、閉じかた、最初に開くタブ | [設定](reference.md#menu-shell) |
| テーマ・フォント | 配色テーマ9種＋カスタム（役割色12色を個別編集）、フォントの差し替え。生成済みのメニューにも適用できる | [カスタマイズ](customize.md) |
| インカム | チャンネル数・チャンネル名、無線の届き方と発話、一時停止 | [運用](operation.md#incom-power) |
| スイッチ | 手元から送るイベントの行編集（ラベル・発火先・イベント名） | [設定](reference.md#trigger) |
| スタッフ名簿 | 常設スタッフの登録。`.asset` として書き出し、別のワールドで読み込める | [運用](operation.md#staff-detection) |
| 既定値 | メガホン・無線・通知音・通知ログ・タイマーなどの初期値 | [設定](reference.md#settings-defaults) |
| 診断・修復 | 設定の過不足を検出してまとめて自動修復する。聴こえ方マトリクス検査つき | [トラブルシューティング](troubleshoot.md) |
| サポート | 問い合わせ用の状態レポートを出す | [トラブルシューティング](troubleshoot.md) |

## できないこと

購入前・導入前に知っておいていただきたい制限です。

| 項目 | 内容 |
|---|---|
| 他の音声ギミックとの同居 | 防音室・ボイスゾーン・音量調整・拡声など、プレイヤーの声を操作するギミックとは**同時に使えません**（[運用](operation.md#incom-power)） |
| プラットフォーム | PC 専用です。Quest 実機での動作確認は行っていません |
| 一斉メッセージの宛先 | スタッフのみです。スタッフ以外へメッセージを出すことはできません |
| メニューを開ける人 | スタッフ状態のプレイヤーだけです |
| テレポート先の数 | 16件までです |
| お気に入り | インスタンス内でのみ有効です。退室するとリセットされます |
| UI の言語 | 日本語です |
