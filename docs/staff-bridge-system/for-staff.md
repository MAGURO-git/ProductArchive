# スタッフの方へ

スタッフになると手元にメニューが出て、テレポート・インカム・一斉メッセージ・タイマー・進行ノートなどが使えます。このページはその操作方法です。

**チャンネルの割り当てや控室の場所など、イベントごとの決めごとは主催の方に確認してください。**

## スタッフになる

スタッフは2種類あります。どちらになるかはイベントによって違います。

- **常設スタッフ**: あなたの VRChat 表示名が名簿に登録されている人。ワールドに入った時点で自動的にスタッフになります
- **当日スタッフ**: ワールド内でスタッフになった人。切替スイッチを自分で押すか、常設スタッフにメニューから追加してもらいます

使えるメニューは同じです。違うのは、ほかの人をスタッフにしたり外したりできるのが常設スタッフだけ、という点です。

!!! info "スイッチの有無と場所は主催の方に確認してください"
    切替スイッチを置くかどうか、どこに置くかはイベントによって異なります。設置していないイベントもあります。

!!! warning "表示名を変えていると認識されません"
    常設スタッフの判定は表示名の完全一致です。前後の空白や絵文字の有無も区別されます。当日は登録したときと同じ表示名で参加してください。

スタッフになると、設定によっては頭の上に目印が表示されます。今そのインスタンスに誰がスタッフとしているかは、ワールド内の一覧ボードでも確認できます。

## メニューを開く

| 環境 | 操作 |
|---|---|
| VR | 右スティックを下に倒して長押し |
| Desktop | キーを長押し（初期設定は Tab キー） |

長押しの時間は 0.5 秒ほどです。キーや長押し時間は主催の方が変更している場合があります。

メニューは**開いた瞬間に目の前へ固定**され、その後は追いかけてきません。開いた場所から離れると自動的に閉じます。もう一度同じ操作をすると閉じられます。

![SBSメニュー](images/menu-teleport.png)

上のタブで画面を切り替えます。灰色になっているタブは、あなたには使えないものです。**どのタブが並んでいるかはイベントによって違います**（主催の方が使わないタブを外していることがあります）。

## テレポート

行き先の一覧から選んで移動します。

1. 行き先を押す（選んだ行に色が付きます）
2. 確定ボタンを押す

誤って飛ばないよう、選ぶ操作と実行する操作が分かれています。

- **登録地点**: 主催の方が用意した地点へ移動します
- **在室スタッフ**: 名前を押すと、その人のところへ移動します。**相手の背後に降り、着地後は相手と同じ方向を向きます**。接客中の相手やスタッフ以外の視界に急に現れないための動きです
- **お気に入り**: 各行の ★ を押すと一覧の上に固定されます。ワールドを出るとリセットされます
- **戻る**: 直前にいた場所と現在地を入れ替えます

同じ場所に複数人が重ならないよう、着地位置は少しばらつきます。

## インカム

### チャンネルに参加する

メニューでチャンネルを選ぶと参加できます。**声が届くのは同じチャンネルに参加している人だけ**です。どのチャンネルを使うかは主催の方の指示に従ってください。

![インカムタブ](images/menu-incom.png)

### 話す

| 方法 | 操作 |
|---|---|
| 発話ボタン | メニュー上のボタンを**押している間だけ**送信されます（設定でトグルにもできます） |
| Desktop のキー | 割り当てたキーで送信されます（既定は T） |
| VR ジェスチャー | **右手**を耳（または肩・胸元）に近づけてトリガーを引きます |

押している間だけ声が届きます。手を離すと送信が止まります。Desktop のキーと VR ジェスチャーはメニューを閉じていても使えます。

押しっぱなしの事故を防ぐため、長く送信し続けると自動的に切れます。

### 聞こえかた

- 同じチャンネルの人には、距離に関係なく声が届きます
- **スタッフ以外や別チャンネルのスタッフには聞こえません**（設定により、近くの人には通常の声として聞こえる場合があります）
- 誰が話しているかはメニューに表示されます
- 自分のチャンネルで誰かが話し始めたとき、小さな音が鳴ります

同じチャンネルでは複数人が同時に話せます。

## メガホン

拡声している間だけ、距離に関係なく**その場の全員（スタッフ以外を含む）**に声が届きます。

始め方は3通りあります。どれを使っても動きは同じです。

| 方法 | 操作 |
|---|---|
| メニューのボタン | メガホンボタンを**長押し**すると始まります |
| Desktop のキー | 割り当てたキーで始まります（既定は割り当てなし。設定タブで決めます） |
| VR ジェスチャー | **左手**を耳（または肩・胸元）に近づけてトリガーを引きます |

ボタンは**長押し**と**トグル**を設定タブで選べます。長押しなら手を離した時点で止まります。トグルなら手を離しても、メニューを閉じても拡声が続くので、切るときはもう一度押してください。VR ジェスチャーはトリガーを引いている間だけです。

!!! tip "インカムとメガホンで手が分かれています"
    VR ジェスチャーは、インカムが**右手**、メガホンが**左手**です。同じ動作で取り合いになりません。手が所定の位置にないときは何も起きないので、物を掴む・UI を押すといった操作の邪魔にもなりません。

インカムで話しているあいだはメガホンを始められません。逆に、メガホン使用中はインカムを送信できません。聞くほうは止まりません。

!!! warning "スタッフ以外にも聞こえます"
    運営どうしの連絡には使わないでください。スタッフ以外への呼びかけ・案内のための機能です。

## 一斉メッセージ

定型文をスタッフへ送れます。宛先は全スタッフか、選んだスタッフです。

受け取ると視界の隅の通知ログに出て、通知音が鳴ります。自分が名指しで指定されたメッセージには目印と枠が付き、長めに残ります。読み返したいときはメッセージタブの受信ログを見てください。

!!! note "スタッフ以外には表示されません"
    送信先はスタッフだけです。また、送信より後に入ってきた人には過去のメッセージは表示されません。

## 通知ログ

視界の隅に、連絡が1行ずつ流れます。メッセージの受信、タイマーの時間切れ、人の出入り、スタッフの増減などがここに出ます。

しばらくすると自動で消えます。**邪魔なときは、設定タブで表示しないようにできます。**

## タイマー・ログ

進行の時間を計るタブです。

- **共有タイマー**: 全員に同じ残り時間が見えます。＋1分／＋5分／＋10分で時間を足して開始します。**開始と取消は2回押し**です（1回目で文言が変わるので、もう一度押すと確定します）
- **ローカルタイマー / ストップウォッチ**: 自分だけのものです。他のスタッフには見えません

同じタブの下側に、誰がいつ入室・退室したかのログが出ます（入室が緑、退室が赤）。「ログを開く」を押すと全画面で一覧できます。

## ノート

進行台本を読むタブです。上のボタンでページを切り替えます。内容は主催の方が用意したもので、全スタッフに同じものが見えます。

下の入力欄は**自分だけのメモ**です。他の人には見えず、ワールドを出ると消えます。

## スイッチ

手元から、ワールドのギミックを動かすタブです（開場ゲートを開ける、など）。行を選んでから確定ボタンを押します。何が並んでいるかはイベントによって違うので、押す前に主催の方に確認してください。

## 設定（自分だけの設定）

設定タブでは、自分の使い勝手だけを調整できます。他のスタッフには影響しません。変更した内容は、同じワールドに入り直しても残ります。

![設定タブ](images/menu-settings.png)

| 項目 | 内容 |
|---|---|
| 操作音 | 自分が操作したときに鳴る音の大きさ |
| 通知音 | インカムの受信音やメッセージの通知音の大きさ |
| UI サイズ | メニューの大きさ |
| UI 距離 | メニューが出る距離（次に開いたときから変わります） |
| 発話ボタン | 押している間だけ送信（長押し）か、押すたびに ON / OFF（トグル）か |
| DT キー発話 | Desktop で発話に使うキー |
| 通知ログ | 連絡を出す位置（左下／表示しない） |

「設定を初期化」ボタンで元に戻せます。

!!! warning "トグルにすると、メニューを閉じても送信が続きます"
    切り忘れると声が流れ続けます。送信中は画面の下に表示が出るので、そこで確認してください（長く続くと自動的に切れます）。VR の耳元ジェスチャーは、設定に関わらず押している間だけです。

## スタッフ管理

常設スタッフだけに表示されるタブです。ワールド内にいる人をその場で当日スタッフにしたり、当日スタッフを外したりできます。

行を選んでから確定ボタンを押す2段階の操作です。常設スタッフは外せないため、一覧に出ません。

## スタッフ限定の場所・設備

主催の方の設定により、次のようなものが置かれている場合があります。操作は不要で、スタッフになると自動的に切り替わります。

- スタッフだけが通れる壁
- スタッフだけが押せるスイッチ
- スタッフだけに見えるオブジェクト
- 在室スタッフの一覧ボード

## 困ったとき

| 症状 | 確認すること |
|---|---|
| スタッフにならない | 表示名が登録時と同じか確認してください。違う場合は主催の方へ連絡してください |
| メニューが出ない | スタッフになっているか確認してください。長押しが足りていないこともあります |
| インカムが聞こえない | 自分がチャンネルに参加しているか確認してください。入り直すと直ることがあります |
| 声が届かない | 発話ボタンを押している間だけ送信されます。押しっぱなしで自動的に切れていることもあります |

いずれも直らない場合は、ワールドから出て入り直すと復帰することがあります。それでも駄目なときは主催の方へ連絡してください。
