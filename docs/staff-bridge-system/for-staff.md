# スタッフの方へ

スタッフになると手元にメニューが出て、テレポート・インカム（無線）・一斉メッセージが使えます。このページはその操作方法です。

**チャンネルの割り当てや控室の場所など、イベントごとの決めごとは主催の方に確認してください。**

## スタッフになる

なり方は3通りで、どれを使うかはイベントによって違います。

- **事前登録**: あなたの VRChat 表示名が登録されていれば、ワールドに入った時点で自動的にスタッフになります
- **切替スイッチ**: ワールド内のスイッチを押すと、自分でスタッフの ON / OFF ができます
- **他のスタッフから付与**: 事前登録されているスタッフが、メニューからその場であなたをスタッフにできます

!!! info "スイッチの有無と場所は主催の方に確認してください"
    切替スイッチを置くかどうか、どこに置くかはイベントによって異なります。設置していないイベントもあります。

!!! warning "表示名を変えていると認識されません"
    事前登録は表示名の完全一致で判定されます。前後の空白や絵文字の有無も区別されます。当日は登録したときと同じ表示名で参加してください。

スタッフになると、設定によっては頭の上に目印が表示されます。今そのインスタンスに誰がスタッフとしているかは、ワールド内の一覧ボードでも確認できます。

## メニューを開く

| 環境 | 操作 |
|---|---|
| VR | 右スティックを下に倒して長押し |
| Desktop | キーを長押し（初期設定は Tab キー） |

長押しの時間は 0.5 秒ほどです。キーや長押し時間は主催の方が変更している場合があります。

メニューは**開いた瞬間に目の前へ固定**され、その後は追いかけてきません。開いた場所から離れると自動的に閉じます。もう一度同じ操作をすると閉じられます。

## テレポート

行き先の一覧から選んで移動します。

1. 行き先を押す（選んだ行に色が付きます）
2. 確定ボタンを押す

誤って飛ばないよう、選ぶ操作と実行する操作が分かれています。

- **登録地点**: 主催の方が用意した地点へ移動します
- **在室スタッフ**: 名前を押すと、その人のところへ移動します。**相手の背後に降り、着地後は相手と同じ方向を向きます**。接客中の相手やお客さんの視界に急に現れないための動きです
- **お気に入り**: 各行の ★ を押すと一覧の上に固定されます。ワールドを出るとリセットされます
- **戻る**: 直前にいた場所と現在地を入れ替えます

同じ場所に複数人が重ならないよう、着地位置は少しばらつきます。

## インカム（無線）

### チャンネルに参加する

メニューでチャンネルを選ぶと参加できます。**声が届くのは同じチャンネルに参加している人だけ**です。どのチャンネルを使うかは主催の方の指示に従ってください。

### 話す

| 方法 | 操作 |
|---|---|
| 発話ボタン | メニュー上のボタンを**押している間だけ**送信されます |
| VR ジェスチャー | 手を耳（または肩・胸元）に近づけてトリガーを引きます |

どちらもトランシーバーと同じで、押している間だけ声が届きます。手を離すと送信が止まります。VR ジェスチャーはメニューを閉じていても使えます。

押しっぱなしの事故を防ぐため、長く送信し続けると自動的に切れます。

### 聞こえかた

- 同じチャンネルの人には、距離に関係なく声が届きます
- **来場者や別チャンネルのスタッフには聞こえません**（設定により、近くの人には通常の声として聞こえる場合があります）
- 誰が話しているかはメニューに表示されます
- 自分のチャンネルで誰かが話し始めたとき、小さな音が鳴ります

同じチャンネルでは複数人が同時に話せます。

## メガホン

メニューのメガホンボタンを**長押し**すると拡声が始まり、押している間だけ、距離に関係なく**その場の全員（来場者を含む）**に声が届きます。手を離すと止まります。

無線で話しているあいだはメガホンを始められません。逆に、メガホン使用中は無線を送信できません（聞くほうは止まりません）。

!!! warning "来場者にも聞こえます"
    運営どうしの連絡には使わないでください。来場者への呼びかけ・案内のための機能です。

## 防音エリア

ワールドによっては、中の会話が外に届きにくい部屋（相談ブースや控室）が用意されていることがあります。中に入ると自動で切り替わり、出ると元に戻ります。

**部屋の中でも無線はそのまま使えます。**来場者の対応をしながら、連絡を聞いたり返したりできます。

!!! warning "完全な防音ではありません"
    遮っているのは距離です。**部屋のすぐ外に立っている人には聞こえます。**聞かれて困る話をするときは、離れた場所へ移動してください。

## 一斉メッセージ

定型文をスタッフへ送れます。宛先は全スタッフか、選んだスタッフです。

受け取ると目の前に通知が出て、通知音が鳴ります。通知はしばらくすると消え、画面の下に履歴が残ります。自分が名指しで指定されたメッセージには目印が付きます。

!!! note "来場者には表示されません"
    送信先はスタッフだけです。また、送信より後に入ってきた人には過去のメッセージは表示されません。

## 設定（自分だけの設定）

設定タブでは、自分の使い勝手だけを調整できます。他のスタッフには影響しません。変更した内容は、同じワールドに入り直しても残ります。

| 項目 | 内容 |
|---|---|
| 操作音 | 自分が操作したときに鳴る音の大きさ |
| 通知音 | 無線の受信音やメッセージの通知音の大きさ |
| UI サイズ | メニューの大きさ |
| UI 距離 | メニューが出る距離（次に開いたときから変わります） |
| 発話ボタン | 押している間だけ送信（長押し）か、押すたびに ON / OFF（トグル）か |
| DT キー発話 | Desktop で発話に使うキー |

「設定を初期化」ボタンで元に戻せます。

!!! warning "トグルにすると、メニューを閉じても送信が続きます"
    切り忘れると声が流れ続けます。送信中は画面の下に表示が出るので、そこで確認してください（長く続くと自動的に切れます）。VR の耳元ジェスチャーは、設定に関わらず押している間だけです。

## スタッフ管理

事前登録されているスタッフだけに表示されるタブです。ワールド内にいる人をその場でスタッフにしたり、そうして付与したスタッフを外したりできます。

行を選んでから確定ボタンを押す2段階の操作です。事前登録されている人は一覧に出ません（外せません）。

## スタッフ限定の場所・設備

主催の方の設定により、次のようなものが置かれている場合があります。操作は不要で、スタッフになると自動的に切り替わります。

- スタッフだけが通れる壁
- スタッフだけが押せるスイッチ
- スタッフだけに見えるオブジェクト
- 在室スタッフの一覧ボード

## 困ったとき

| 症状 | 確認すること |
|---|---|
| スタッフにならない | 表示名が登録時と同じか確認してください。違う場合は主催の方へ連絡してください |
| メニューが出ない | スタッフになっているか確認してください。長押しが足りていないこともあります |
| インカムが聞こえない | 自分がチャンネルに参加しているか確認してください。入り直すと直ることがあります |
| 声が届かない | 発話ボタンを押している間だけ送信されます。押しっぱなしで自動的に切れていることもあります |

いずれも直らない場合は、ワールドから出て入り直すと復帰することがあります。それでも駄目なときは主催の方へ連絡してください。
