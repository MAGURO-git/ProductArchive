## ギミックを個別に追加する { #single-prefab }

「Prefab を個別に置く」ページのボタンから追加できます（スタッフ判定ギミックは1ワールドあたり最大128個）。配置と同時に名簿へ自動で接続されます。

| ボタン | 内容 |
|---|---|
| スタッフ切替スイッチ | 押すと自分がスタッフ ON/OFF になるスイッチ |
| スタッフ専用スイッチ | スタッフだけが操作できるスイッチ（スタッフ以外が押すと拒否メッセージが出る） |
| スタッフゲート | スタッフだけ通れる壁 |
| 頭上マーカー | スタッフの頭上に出す目印。置き場所は問いません（実行中は自動で頭上へ移動します） |
| 在室スタッフ一覧ボード | 入室中のスタッフ名を表示するボード |
| 共有タイマーボード | 共有タイマーの残り時間を表示するボード。見出しは配置後に Inspector で変えられる |
| ログボード | SBS に起きたことを時刻順に流すボード。板のボタンで種別を絞り、過去へさかのぼれる |

## 既存オブジェクトをスタッフ限定にする { #staff-only-existing }

Hierarchyでオブジェクトを選択し、右クリック > **GameObject > MGR > Staff Bridge System** から選びます。

| メニュー | 動作 |
|---|---|
| スタッフだけ見えるようにする > **Renderer・Collider 制御（標準）** | 自分の見た目・当たり判定を切り替える（音などは継続） |
| スタッフだけ見えるようにする > **GameObject.SetActive 制御（丸ごと）** | オブジェクトを丸ごと非アクティブにする（音の再生なども停止） |
| スタッフ以外だけ見えるようにする（スタッフには隠す） > **Renderer・Collider 制御（標準）** | 上記の逆。スタッフのときだけ見た目・当たり判定を隠す |
| スタッフ以外だけ見えるようにする（スタッフには隠す） > **GameObject.SetActive 制御（丸ごと）** | 上記の逆。スタッフのときだけ丸ごと非アクティブにする |
| **スタッフだけ押せるボタンにする** | 既存のインタラクトをスタッフ限定にする（Collider が無い場合は BoxCollider を自動で追加） |
| **スタッフだけ通れる壁（ゲート）にする** | スタッフ以外だけを通さない壁にする（Collider が無い場合は BoxCollider を自動で追加） |

同じ項目は **Tools > MGR > Staff Bridge System > 選択オブジェクトに追加** からも実行できます。

2つの制御方法の違いは [設定リファレンス](reference.md#staff-only-objects) を参照してください。


## 既存のワールドを更新する { #update }

事前にプロジェクトのバックアップを取ってから行ってください。

1. 新しい unitypackage をプロジェクトへインポートします。
2. セットアップウィンドウの「診断・修復」を開き、追加・修復項目を実行します。
    - **声の大きさの調整を追加** / **前面表示に設定**（v1.1.0 向け）：該当項目が表示されていれば実行します。
    - **周りの声を下げるスライダーを追加**（v1.2.0 向け）：メニューをアンパック等で使用している場合に表示されます。追加した行は、設定の「基本」タブの一番下に「インカム使用中の周りの声」として入ります。「インカム」タブの表示は前の版のままですが、メニューを作り直すと v1.2.0 の配置になります。ボタンを押して機能を追加してください（Prefab のまま使用している場合は、後述の「インカムを再リンク」で接続されます）。
    - **プロップタブ（未配置）**（v1.2.0 向け）：プロップを使用する場合のみ「プロップタブを追加」を押してください（初期状態は無効）。
    - **スイッチのカテゴリ分けとお気に入り**（v1.2.0 向け）：Prefab のままお使いの場合は、インポートだけで、スイッチタブに「すべて」「お気に入り」のタブと、各行の★が加わります（カテゴリは、セットアップウィンドウの「スイッチ」で登録するまで増えません）。アンパック等でお使いの場合は、診断に「スイッチのカテゴリ分けとお気に入り（未配置）」と表示されます（お知らせだけで、ボタンはありません）。使うには、セットアップウィンドウの「メニュー構成」で「この構成でメニューを作り直す」を押すと、スイッチの設定を引き継いだまま、タブと★が加わります。ただし、メニューは新しいオブジェクトになるので、見た目や階層を手で変えている場合は、先にバックアップを取ってください（Ctrl+Z で元に戻せます）。使わない場合は、そのままで問題ありません。★は、セットアップウィンドウの「スイッチ」ページを一度開いたとき、またはアップロードしたときに表示されます（行IDが振られるまで、ClientSim では★が出ません）。
3. Prefab のままお使いの場合、インポート直後に「インカムの接続」と「周りの声を下げる（PA Supervisor接続）」に関する警告が一度表示されることがあります。「インカムを再リンク」を押すと解消し、周りの声を下げる機能のコンポーネントも自動接続されます（警告が残る場合は「PA Supervisorへ接続」を押してください）。
4. ClientSim でメニュー操作やインカム通話を確認します。

※同梱サンプルシーンを直接編集している場合は、インポートで上書きされる前に別名で保存してください。
