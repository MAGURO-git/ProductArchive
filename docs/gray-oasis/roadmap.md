# 開発状況

GRAY OASIS で、いま作っている機能と、今後対応する予定の機能、検討している機能を載せています。内容と時期は変わることがあります。

この内容は 2026年11月8日 時点のものです。

公開済みの変更は[更新履歴](changelog.md)を参照してください。

## 開発中 { #in-progress }

次の更新に向けて作業している機能です。最適化を中心に作業しています。

### 機能改善

- テクスチャの最適化：容量を削減
    - 見た目への影響を抑えながら最適化
    - 対象は Bakery 版とビルトインライトマッパー版
- テクスチャの外部依存の解消：追加テクスチャを外部ストレージから取得する手順を廃止

## 対応予定 { #planned }

対応することは決めている機能です。

### 2.0.0

2.0.0 に向けて開発を進めています。

#### 新機能

- 音の追加：効果音と環境音を増やす

#### 機能改善

- 見た目の改善：家具、配色、照明を見直し
- アセット依存の削減
    - シェーダー：できるだけ orels Unity Shaders に移行
    - Filamented：削除予定
    - ギミック：できるだけ自作のギミックに置き換え

## 検討中 { #considering }

いただいた要望のうち、対応するかどうかや、どの形で提供するかを検討している機能です。

現在、公開している検討中の機能はありません。
