<span class="badge badge--vrc">VRChat World</span>

## 必要環境

| 項目 | 内容 |
|---|---|
| Unity | 2022.3.6f1（他バージョンでの動作は保証していません） |
| ワールド容量 | 約75〜80MB |
| 別途導入が必要なアセット | VizVid / KineL Player Counter / VRChat向けUI集＋スイッチ（[導入](install.md)を参照） |

入室音・プレイヤーカウンター・ビデオプレイヤー・ミラー・ペンなどのギミックは設定済みです。
