# 使用アセット

| アセット | 配布元 | 別途ダウンロード |
|---|---|---|
| VizVid | [JLChnToZ/VVMW](https://github.com/JLChnToZ/VVMW) | **必要**（同梱していません） |
| 【無料】VRChat向けUI集＋スイッチ（Solitude） | [BOOTH](https://kakushop.booth.pm/items/5345171) | **必要**（同梱していません） |
| KineL Player Counter（nirila's VPM Repository） | <https://vpm.niri.la/howtouse/> | **必要**（同梱していません） |
| 【無料】オブジェクトリセットギミック（#たくあん屋） | [BOOTH](https://booth.pm/ja/items/4490020) | 不要 |
| 【無料】VRChat Udon 入退室ログアセット（ねこばこ屋） | [BOOTH](https://booth.pm/ja/items/2683599) | 不要 |
| アズキド時計（UDON, VRChat）（Wmup） | [BOOTH](https://booth.pm/ja/items/2225650) | 不要 |
| 【自動切換】Smart Mirror【VRCSDK3 / U#】（まめもやシステムズ 蕪） | [BOOTH](https://booth.pm/ja/items/3292060) | 不要 |
| VRCPlayersOnlyMirror（背景なし）（temporal） | [BOOTH](https://booth.pm/ja/items/2685621) | 不要 |
| PLATEAU（国土交通省） | <https://www.mlit.go.jp/plateau/> | 不要 |

「別途ダウンロードが必要」のアセットは本製品に含まれていません。入手先と導入の順序は [導入](install.md) を参照してください。

オブジェクトリセットギミックはデータを同梱しておらず、ギミックを参考にさせていただいています。

## 出典

3D都市モデル（Project PLATEAU）堺市（2022年度）（<https://www.geospatial.jp/ckan/dataset/plateau-27140-sakai-shi-2022>）を加工してスカイボックスに使用しています。
