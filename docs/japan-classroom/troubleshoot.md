# トラブルシューティング

Japan Classroom の導入や改変時に発生しやすい問題と解決策です。

---

## 分割アーカイブが解凍できない・壊れていると表示される

**原因**: `part1.exe`、`part2.rar`、`part3.rar` のいずれかのダウンロードが不完全であるか、別々のフォルダに配置されています。

**対処**:
1. 3つのファイル（`part1.exe`, `part2.rar`, `part3.rar`）がすべて同じフォルダに存在することを確認してください。
2. ダウンロード中に接続が切れてファイルサイズが小さくなっていないか、BOOTHの購入履歴から再度ダウンロードして確認してください。
3. Windows Defender 等のセキュリティソフトが `.exe` の実行をブロックしている場合は、一時的に許可してください。

---

## 窓ガラスや黒板のマテリアルがピンク色になる

**原因**: 必要なシェーダーの参照が外れているか、プロジェクト内にシェーダーが不足しています。

**対処**:
1. ピンク色になっているマテリアルを選択し、Inspector で指定されている Shader を確認します。
2. Unity 標準の Standard シェーダー、または透明表現用のシェーダーを再割り当てしてください。

---

## 散らかった机や黒板消しがリセットボタンで戻らない

**原因**: オブジェクトのルート階層を変更したか、リセットスクリプト内の参照が外れています。

**対処**:
1. 操作パネルの「リセット」ボタンの Inspector を開き、`UdonBehaviour` の対象オブジェクト一覧に Missing がないか確認してください。
2. リセット対象オブジェクトの Tag や Layer が変更されていないか確認してください。

---

## チャイムの音が鳴らない

**原因**: AudioSource の設定、または Udon スクリプトの時刻取得が停止しています。

**対処**:
1. Hierarchy からチャイム用 AudioSource を選択し、Volume が 0 になっていないか、Mute されていないか確認してください。
2. Unity Play モード（ClientSim）ではシステム時刻と連動するため、正時（00分）まで待つか、テスト用メソッドを発火させて再生を確認してください。
