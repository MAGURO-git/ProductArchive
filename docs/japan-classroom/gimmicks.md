# ギミック一覧

## 操作パネル

1. 背景ありミラー
2. プレイヤーのみのミラー
3. ポストプロセッシング
4. パーティクル
5. ビデオプレイヤー
6. つかめるオブジェクトのリセット
7. ギミックの表示をオフにする（写真撮影向け）

## 常時動作するもの

- 教室後方のエアコンの音
- 蛍光灯の点灯
- 1時間ごとのチャイム
- 扇風機のアニメーションと音

## つかめるオブジェクト

- 黒板けし・ちりとり・ほうき（小）・ほうき — ワールドのコライダーに接触するとパーティクルと音が出ます
- 黒板けし — 黒板に接触させると音が鳴ります。5秒ほど接触させてから離すと音が終わります
- 定規類・辞書類・椅子
- ランダムにオブジェクトが発生するギミック（リセット機能つき）
