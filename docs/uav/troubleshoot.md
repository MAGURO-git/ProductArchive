# トラブルシューティング

無人航空機 / UAV の導入時によくある問題と解決策です。

---

## アニメーションが再生されない・プロペラが回らない

**原因**: Prefab に Animator コンポーネントがアタッチされていないか、Controller の割り当てが外れています。

**対処**:
1. Hierarchy で UAV のルートオブジェクトを選択します。
2. Inspector の `Animator` コンポーネントで、**Controller** 欄に同梱の Animator Controller が割り当てられているか確認してください。
3. `Apply Root Motion` のチェックを外すか、必要に応じて設定を調整してください。

---

## マテリアルがピンク色になる

**原因**: Standard Shader 以外の特殊エフェクト用シェーダーの参照が外れています。

**対処**:
1. ピンク色になっているマテリアルを選択します。
2. Unity 標準の Standard シェーダーを再割り当てし、Albedo / Metallic / Normal Map のスロットに同梱テクスチャを割り当て直してください。

---

## プレイヤーが機体をすり抜けてしまう

**原因**: 3Dモデル単体には当たり判定（コライダー）が付属していません。

**対処**:
1. 機体オブジェクトまたはその子要素に `Box Collider` を追加して、胴体や主翼の当たり判定を設定してください。
2. 複雑な形状に密着させたい場合は、主翼や機首ごとに分割したシンプルなコライダーを組み合わせることを推奨します。
