# トラブルシューティング

ハンドグレネードギミックの導入・運用時によくある問題と解決策です。

---

## PhysBone を掴んで固定しても爆発しない

**原因**: 最も多い原因は「セーフティが解除されていない」「PhysBone の設定漏れ」「パラメータ名の入力ミス」です。

**対処**:
1. **セーフティの確認**: アバターのエクスプレッションメニューで `HandGrenade_ON` が ON になっているか確認してください。
2. **Posing の確認**: PhysBone の `Allow Posing` にチェックが入っているか確認してください。掴む（Grab）だけではなく、固定（Pose）された瞬間に発火する仕組みです。
3. **パラメータ名の再確認**: `MA_GranadeGimmick` の Inspector に表示されているパラメータ名と、PhysBone の `Parameter` 欄の文字列が一文字の違いもなく一致しているか確認してください（末尾の余計な空白にも注意）。

---

## Expression Menu にトグルボタンが表示されない

**原因**: Modular Avatar の結合処理が失敗しているか、アバターのメニュー階層の上限に達しています。

**対処**:
1. プロジェクト内に Modular Avatar が正常に導入されているか確認してください。
2. アバターのエクスプレッションメニューのルート（トップ層）の項目数がすでに上限（8個）に達している場合、Modular Avatar が自動追加できないことがあります。サブメニューを作成して空き枠を作ってください。

---

## 爆発エフェクトがアバターの体から離れた場所で出る

**原因**: `MA_GranadeGimmick` のルート Transform がアバターの中心から大きくズレています。

**対処**:
1. Hierarchy で `MA_GranadeGimmick` を選択します。
2. Scene ビュー上で、アバターの胴体や腰の位置にギズモ（矢印）が来るように Position を調整してください。

---

## 他人から爆発が見えない・音が聞こえない

**原因**: VRChat 内で同期パラメータが上限に達しているか、セーフティ設定によりパーティクルが制限されています。

**対処**:
1. アバターの同期パラメータ（Synced Parameters）の合計容量が 256 bits を超えていないか、アバタービルド画面で確認してください。
2. 他プレイヤー側の Safety 設定（Avatar Performance / Particle Display）でパーティクルが無効化されていないか確認してください。
