# カスタマイズ

エフェクトの位置や音量、連動する PhysBone を変更・調整する手順です。

---

## 爆発位置とスケールの微調整

アバターの体格（高身長・低身長）に合わせて爆発エフェクトの発生位置を調整できます。

1. Hierarchy で `MA_GranadeGimmick` を選択します。
2. Scene ビュー上で、Transform の **Position（位置）** を動かして腰や手の高さに合わせます。
3. エフェクト全体の大きさを変えたい場合は、Transform の **Scale（拡縮）** を `0.8` や `1.2` などに変更してください。

---

## 音量の調整

ワールド内で爆発音が大きすぎると感じる場合の調整方法です。

1. `MA_GranadeGimmick` の子オブジェクトにある `AudioSource`（爆発SE用）を選択します。
2. Inspector の **Volume** スライダーを下げてお好みの音量に調整します。
3. **Max Distance**（最大減衰距離）を小さく設定すると、遠くのプレイヤーへ届く音を小さく抑えることができます。

---

## 別のパーツで発火させる（複数登録）

スカート以外の場所（例: 帽子、リボン、髪）にも発火トリガーを設定できます。

1. 発火させたい対象の PhysBone コンポーネントを選択します。
2. `Grab & Pose` の `Allow Grabbing` と `Allow Posing` を **True** にします。
3. `Options` の `Parameter` に、同じ手榴弾のパラメータ名を貼り付けます。
4. これにより、どちらの部位を掴んで固定しても同じように発火させることが可能になります。
