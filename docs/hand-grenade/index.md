# ハンドグレネードギミック

<span class="badge badge--vrc">VRChat アバター</span>

PhysBone（スカートやアホ毛など）を掴んで固定すると、手榴弾のパーティクルエフェクトが発生するアバター用ギミックです。Modular Avatar に対応しています。

- 商品ページ: [BOOTH](https://maguro-vrc.booth.pm/items/6215675)

## 必要環境

| 項目 | 内容 |
|---|---|
| Unity | 2022.3.22f1 |
| 容量 | 約46MB |
| 必須アセット | [Modular Avatar](https://modular-avatar.nadena.dev/ja) ／ [lilToon](https://lilxyzw.github.io/lilToon/) |

3Dモデル・パーティクルエフェクト・サウンドが入っています。衣装とアバターは付属しません。

## 導入

導入手順は動画で公開しています。

<https://youtu.be/XyxX2FqC6Us>

## 使用上の注意

- 音とパーティクルエフェクトが発生します。周囲の状況を確認してから使用してください
- 複数人から連続して動作させた場合など、見た目が同期しないことがあります
- 使い終わったらギミックのメニューからセーフティをかけておくと、意図せずパーティクルが発生しません
