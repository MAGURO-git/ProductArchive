# トラブルシューティング

Light Set の導入・ベイク時によくある問題と解決策です。

---

## ライトを配置しても部屋が明るくならない

**原因**: ライトの Mode が `Baked` になっており、ベイクが未実行です。

**対処**:
1. Mode が `Baked` のライトは、ライトマップのベイクを実行するまでリアルタイムの光を発しません。
2. 配置テスト中のみ一時的に Mode を `Realtime` に切り替えるか、**Window > Rendering > Lighting** から「Generate Lighting」を実行してください。

---

## ベイク後に照明器具の周りの影が黒く潰れる・乱れる

**原因**: ライトマップ解像度が不足しているか、UV2のパディング設定が狭すぎます。

**対処**:
1. Lighting ウィンドウの `Lightmapping Settings` で、Lightmap Resolution を上げてベイクしてください。
2. FBX モデルの Model インポート設定で、「Generate Lightmap UVs」の Pack Margin を少し広げて再ベイクしてください（同梱モデルは調整済みですが、極端に解像度が低いとアーティファクトが発生します）。

---

## マテリアルがピンク色になる

**原因**: シェーダーの参照が外れています。

**対処**:
1. マテリアルを選択し、Unity 標準の Standard シェーダーまたはモバイル向けの軽量シェーダーを再割り当てしてください。
2. Emission（自己発光）プロパティを有効にし、発光カラーを設定することで、電球やカバー部分の光る表現を再現できます。
