## アセットの特徴

- **豊富な照明器具バリエーション** — 天井埋め込みダウンライト、ペンダントライト、スポットライトなど、空間演出に合わせた多彩なデザイン（Vol.1 / Vol.2）を収録。
- **ベイク最適化済み** — ライトマップベイク時の影の乱れやアーティファクトを防ぐため、UV2設定とマテリアルを調整済みです。
- **配置するだけの簡単設計** — 3Dモデル、マテリアル、Lightコンポーネントがセットアップされており、シーンに置くだけですぐに使用できます。

## ご購入前の確認事項

- **ライトマップのベイクを推奨**:
  リアルタイムライトを大量に配置すると描画負荷が高くなります。ワールド全体の最適化のため、ライトマップのベイク（Baked または Mixed）での運用を推奨します。
